## 1. Lifecycle Overview

CogniX enforces a disciplined lifecycle for all enterprise innovation experiments. Every experiment progresses through defined maturity gates.

```text
  [ Concept ] 
      ↓
  [ Research ]
      ↓
  [ Prototype ]  <--- Minimum required maturity for interactive demo
      ↓
  [ Pilot Ready ]
      ↓
  [ Accelerator ]
      ↓
  [ Industry Pattern ]
      
  ( Alternate Outcome: [ Retired ] at any stage )
```

---

## 2. Gateway Entry & Exit Conditions

### 2.1 State 1: Concept
- **Definition:** An initial hypothesis addressing a non-trivial enterprise decision friction or operational breakdown.
- **Entry Criteria:** Articulation of a provocative executive question and problem statement.
- **Exit Criteria:** Approved business value hypothesis and initial scenario outline.

### 2.2 State 2: Research
- **Definition:** Deep-dive analysis of industry paradigms, data requirements, and technical feasibility.
- **Entry Criteria:** Approval of Concept by Innovation Steering Committee.
- **Exit Criteria:** Defined causal data model, mock/synthetic dataset specifications, and mathematical/AI logic blueprint.

### 2.3 State 3: Prototype (Flagship Demo Standard)
- **Definition:** A fully interactive, client-facing demonstration environment built in CogniX.
- **Entry Criteria:** Completion of Research phase.
- **Exit Criteria:** Working interactive scenario UI, evidence panel integration, Gemini summary logic, and successful execution of 3-minute executive walkthrough without errors.

### 2.4 State 4: Pilot Ready
- **Definition:** Experiment hardened with configurable data adapters ready to connect to client test environments.
- **Entry Criteria:** Validation in executive demonstrations with at least two target enterprise clients.
- **Exit Criteria:** Documented API integration specs, client context configuration schema, and security/privacy audit.

### 2.5 State 5: Accelerator
- **Definition:** A standardized, reusable G10X software package and implementation methodology ready for deployment by G10X consulting teams.
- **Entry Criteria:** Successful completion of a client proof-of-concept or pilot implementation.
- **Exit Criteria:** Refactored core modules, deployment scripts, user documentation, and IP asset registration.

### 2.6 State 6: Industry Pattern
- **Definition:** A widely recognized enterprise decision architecture published as a G10X thought-leadership pattern.
- **Entry Criteria:** Multiple successful enterprise deployments across an industry sector.

---

## 3. The Retirement State (`Retired`)

Retirement is an explicit, positive governance outcome in CogniX. An experiment is retired if:
1. Executive client demonstrations fail to generate sufficient commercial resonance or curiosity.
2. Market/technical assumptions prove invalid or economically unviable.
3. The underlying enterprise problem is rendered obsolete by platform evolutions.

**Retirement Protocol:**
- Document all learnings in `Enterprise Memory`.
- Archive experiment assets and metadata into `docs/experiments/archive/`.
- Remove from active `Innovation Portfolio` view while preserving IP provenance.
